# Probentrainer

Übungs-App für Proben und Schulaufgaben (Bayern, Klasse 1–9) mit Notenschlüssel, Lese-/Hörproben, Lernkartei und Notenbuch.

**App öffnen:** `https://DEIN-NAME.github.io/probentrainer/`

- Läuft offline, sobald sie einmal geöffnet wurde.
- Alle Daten (Kinder, Ergebnisse, Noten) bleiben **nur auf dem jeweiligen Gerät**. Im Repository liegen keine persönlichen Daten.
- Installieren: iPhone/iPad → Safari → Teilen → „Zum Home-Bildschirm“. Android → Chrome → ⋮ → „App installieren“.

## Update einspielen
1. Neue `index.html` hochladen (Add file → Upload files → Commit).
2. In `sw.js` die Zeile `VERSION=` ändern (z. B. neues Datum), damit Geräte das Update laden.
